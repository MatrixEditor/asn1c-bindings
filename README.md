# ASN.1 Compiler with Python C extension support

## About

ASN.1 to C compiler takes the ASN.1 module files (example) and generates
the C++ compatible C source code. That code can be used to serialize
the native C structures into compact and unambiguous BER/OER/PER/XER/JER-based
data files, and deserialize the files back. **However, this variant also**
**supports automatic generation of Python C extensions.**

> [!NOTE]
> **The documentation is now available online: [matrixeditor.github.io/asn1c-bindings](https://matrixeditor.github.io/asn1c-bindings/).**
